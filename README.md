# График руководства

Общий календарь Председателя Правления и руководителей АО «Самрук-Энерго» в фирменном стиле.

Рабочая версия: https://claude.ai/artifact/9wMxVBQ3sA3Q1qtzTTFvMV

## Что умеет

- Графики руководителей рядом по часам (день), неделя и список в формате прежнего Excel.
- Секретарь назначает встречи в любом графике; руководитель ведёт свой.
- Совместные встречи появляются у всех участников, пересечения подсвечиваются.
- Комментарии к встречам.
- «Найти окно»: время, когда свободны все выбранные.
- «План на день»: текст для WhatsApp и почты, скачивание Excel.
- Повторяющиеся встречи, отпуск и командировка, «Добавить в Outlook».
- Адаптивная вёрстка для телефона и компьютера.

## Как устроено

Один файл `index.html` без сборки. Данные (руководители, встречи, комментарии, отсутствия) хранятся на сервере claude.ai через возможности артефакта `db` и `user`, поэтому страница работает только внутри claude.ai. Если открыть `index.html` отдельно, появится сообщение «Календарь недоступен в этом окне».

Роли задаются уровнем доступа в меню «Поделиться» артефакта:

| Роль | Доступ | Что может |
|---|---|---|
| Секретарь | Editor | Назначает встречи во всех графиках, ведёт список руководителей |
| Руководитель или помощник | Contributor | Ведёт свой график, комментирует, отмечает отсутствие |
| Просмотр | Viewer | Видит все графики |

## Файлы

- `logo-color.svg`, `mark.svg` — логотип и знак из дизайн-системы «Самрук-Энерго».
